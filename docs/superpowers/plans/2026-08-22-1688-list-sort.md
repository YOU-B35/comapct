# 1688 模块列表排序 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 1688 模块四个列表（商品分类、爆款/今日爆款/近期销量、爆款追踪、订单）的数值列和时间列增加点击表头排序。

**Architecture:** 全部为前端改动：使用 Element Plus `el-table` 原生 `sortable`；模板渲染的数值列配 `:sort-method` 按原始字段比较（空值按 0）。后端分页列表仅当前页排序。完成后用 `scripts/deploy-web-only.js` 推送线上。

**Tech Stack:** Vue 3 + Element Plus（el-table）、Node（构建/部署脚本）。

## Global Constraints

- 只改四个组件：`Alibaba1688ProductPanel.vue`、`Alibaba1688ProductAnalyticsPanel.vue`、`Alibaba1688PeerBestsellersPanel.vue`、`Alibaba1688OrderDetailsPanel.vue`。
- 数值列排序用 `Number(a.字段 || 0) - Number(b.字段 || 0)`；时间列直接 `sortable`（字符串即时间序）。
- 不改 API、不改分页逻辑、不新增依赖、不动其他模块。
- 后端分页列表（订单、爆款追踪）仅当前页排序（本次不做服务端排序）。
