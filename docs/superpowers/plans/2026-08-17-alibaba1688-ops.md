# 1688 Ops Real Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the existing 1688 Vue shell to a real Java `/api/1688` backend with local Playwright crawl (login probe + purchase sync), including delay/stockout alerts and 90-day supplier ranking.

**Architecture:** Vertical copy of AliExpress: Java package `com.crosshub.alibaba1688` orchestrates jobs and spawns `operational_crawl.py --platform 1688`; Python registers an operational adapter that uses tenant profile `.1688-browser-profile/tenant-{id}`; Vue `alibaba1688Api.js` polls jobs and loads `/operational`, falling back to Demo when Java is down.

**Tech Stack:** Spring Boot + SQLite (Java), Playwright (Python), Vue3 + Element Plus, existing `platform_account` binding.

**Spec:** `docs/superpowers/specs/2026-08-17-alibaba1688-ops-design.md`

## Global Constraints

- Platform key / API: `1688` / `/api/1688` (Java package name `alibaba1688`).
- Crawl runs **local Windows only**; do not deploy Playwright to the remote server.
- No purchase reconciliation this phase.
- Do not create a third primary Tab; ranking lives in supplier panel upper section.
- Extend existing shell; do not scaffold a new module route.
- Login probe is `POST /api/1688/crawl` with `jobType=login_probe` (no separate `/login/probe`).
- Sync strategy: **upsert only** — never wipe tables on success/partial/failure.
- Day0 attachment required before claiming live crawl selectors work; until then fixture/fixture-path tests are allowed for Java rules.
- After any `backend/java/` change: `powershell -File scripts\restart-java-api.ps1` and confirm `:18080` listens.

```java
public final class Alibaba1688PurchaseRules {
    private Alibaba1688PurchaseRules() {}

    public static boolean isReceivedOrCompleted(String status) {
        String s = status == null ? "" : status.trim().toLowerCase(Locale.ROOT);
        return s.equals("completed") || s.contains("完成") || s.contains("签收");
    }

    public static boolean isDelayed(String expectedArrivalAt, String status, LocalDateTime now) {
        if (isReceivedOrCompleted(status)) return false;
        if (expectedArrivalAt == null || expectedArrivalAt.isBlank()) return false;
        LocalDateTime eta = parseFlexible(expectedArrivalAt);
        return eta != null && eta.isBefore(now);
    }

    public static boolean isStockout(String statusText, Collection<String> keywords) {
        String text = statusText == null ? "" : statusText;
        for (String k : keywords) {
            if (k != null && !k.isBlank() && text.contains(k)) return true;
        }
        return false;
    }
}
```
