## 4. Docker 容器（CrossHub 相关）

> 实勘时间：2026-07-31（SSH `docker ps`）

### 4.1 本项目容器

| 容器名 | 镜像 | 端口映射 | 状态（实勘） | 职责 |
|--------|------|----------|--------------|------|
| **crosshub-java** | `crosshub-java:latest` | `127.0.0.1:18080→18080` | Up | 主 API（Temu/Amazon/AE/Agent/仓库等） |
| **crosshub-express** | `crosshub-express:latest` | `127.0.0.1:18081→18081` | Up | 仅健康检查桩 |
| **crosshub-python-worker** | `crosshub-python-worker:latest` | （compose 有定义） | 实勘时**未在跑** | Monitor/证据类 worker（可选） |

启动目录：`/data/crosshub/`  

```bash
cd /data/crosshub
docker compose -f docker-compose.yml up -d --force-recreate crosshub-java
docker logs --since 30m crosshub-java
curl -s http://127.0.0.1:18080/api/health
```

### 4.2 Java 容器要点

- 入口：`java -jar /app/app.jar --server.port=18080`  
- Profile：`SPRING_PROFILES_ACTIVE=prod`  
- DB：`CROSSHUB_DB_PATH=/data/crosshub.db`（即宿主机 `/data/crosshub/data/crosshub.db`）  
- Agent 模式：`CROSSHUB_CRAWLER_USE_AGENT=true`（日批/爬取依赖 Helper，不在服务器上跑有头浏览器）  
- 重建镜像常见流程：本机 `mvn package` → 上传 `app.jar` → 服务器 `docker build -f Dockerfile.java` → `compose up -d --force-recreate crosshub-java`  
- 脚本：`scripts/_deploy_java_jar_only.js`（**SKIP_DB**，禁止覆盖生产库）
